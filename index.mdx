## Getting Started

<Steps>
  <Step title="Clone the repository">
    Clone the example-modules repository into your PrestaShop `modules` directory:
    ```bash
    git clone https://github.com/PrestaShop/example-modules.git
    ```
  </Step>
  <Step title="Pick a module">
    Browse the [Module Examples](/modules/democontrollertabs) section to find the pattern you want to learn. Each module folder is self-contained.
  </Step>
  <Step title="Install dependencies">
    Enter the module directory and run Composer to install dependencies:
    ```bash
    cd modules/<module_name>
    composer install
    ```
  </Step>
  <Step title="Install the module">
    Install via the PrestaShop console or the Back Office Module Manager:
    ```bash
    php bin/console prestashop:module install <module_name>
    ```
  </Step>
</Steps>

## Compatibility

All modules in the `master` branch target **PrestaShop 9.0.0 and above**. For examples compatible with PrestaShop 8.x, see the [`8.x` branch](https://github.com/PrestaShop/example-modules/tree/8.x) of the repository.

<Note>
  These modules are reference implementations, not production-ready packages. Use them as blueprints to understand patterns, then adapt the code to your own module's requirements.
</Note>
